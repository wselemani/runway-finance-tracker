RUNWAY- Student Finance Tracker

Tagline: Know how far your money goes.

About the Project
Runway is a responsive student finance tracker that helps mainly Collge students record expenses,monitor spending and manage a monthly budget.

Features
1. add,edit and delete expenses
2. categorize expense as needs or wants
3. Set and save a monthly budget.

4. Convert amounts between RWF, USD, and MWK using manually entered exchange rates.

5. Search and sort expense records.

6. Import and export expense data as JSON.

7. Save data in the browser using localStorage.

8. Validate expense inputs and highlight search matches.

Technologies
1. HTML
2. CSS
3. Javascript
4. Browser localStorage

How To Run
-Open index.html in a browser, or run the project using VS Code Live Server extension.
